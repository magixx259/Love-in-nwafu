# 素材工作目录

本目录存放确认可分享的加工素材与来源说明；目前只有目录说明，没有正式美术或音频文件。

计划使用以下分类，制作到相应素材时再创建目录：

```text
assets/
  backgrounds/    校园和室内背景
  characters/    角色立绘，按 ch01、ch02、ch03 分目录
  maps/          校园地图
  ui/            学院卡片、按钮及界面装饰
  minigames/     结构辨认图、三视图等教学示意图
  audio/bgm/     背景音乐
  audio/sfx/     音效和氛围音
  fonts/         额外字体及其许可
  licenses/      随素材分发的许可文本和署名说明
```

文件名使用小写英文、数字和下划线，与素材清单中的编号对应。保留可编辑原稿；实际游戏所需导出文件在创建工程后放入 `game/` 下对应目录，不把原始工作文件全部打包进游戏。

个人原照、未确认许可的网上图片、参考游戏截图、私人故事笔记统一放在本地 `private/`，不放入本目录。每次加入正式文件时，先更新 `docs/day01/04-source-register.md`。
