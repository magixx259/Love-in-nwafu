# 美术与音频制作目录

目录已创建，目前只有说明和空目录占位，没有正式立绘、模型、背景或音乐。

- `characters/`：按角色编号管理概念稿、立绘、表情、CG、Live2D 和 3D 模型。
- `backgrounds/`：按场景管理校门、动医楼、第五餐厅和宿舍美术。
- `maps/`：地图绘制原稿。
- `ui/`：对话框、按钮、学院卡片和界面装饰。
- `cg/`：多人或跨场景剧情插画。
- `minigames/`：课程互动示意图。
- `audio/bgm/`、`audio/sfx/`、`audio/ambience/`、`audio/voice/`：配乐、音效、环境声及配音。
- `fonts/`：额外字体及其许可。
- `licenses/`：可分发资源的许可证和署名说明。

## 制作稿与运行素材

可编辑原稿放在本目录相应分类中，文件名使用小写英文、数字和下划线。Ren’Py 运行所需的选定导出文件放 `game/images/`、`game/audio/` 或 `game/fonts/`。原始生活照、商业游戏参考及许可未确认的图片留在 `private/`。

角色建模不等于必须做 3D。静态立绘、Live2D 和 3D 使用不同目录；当前只计划用占位姓名框和静态立绘完成第一版，动态模型尚未决定是否制作。

每次加入正式资源，更新[来源记录](../docs/day01/04-source-register.md)。详细目录说明见[文件夹导航](../docs/project/folder-guide.md)。
