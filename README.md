# Love in NWAFU · 西农校园恋爱游戏

以西北农林科技大学校园生活为背景的单机视觉小说，计划支持玩家制作 MOD。

当前阶段：已有可运行的试玩版（v0.1-demo）——标题菜单、约 1 分钟的序章预告、动物医学院「第一天」完整流程（含一次四选一的专业小知识互动）。背景与立绘仍是占位素材，正式美术、音乐尚未开始。

## 如何运行

1. 用 Ren'Py 8.3.7 启动器打开本目录（项目根目录就是本目录），或直接运行 `G:\renpy\renpy-8.3.7-sdk\renpy.exe E:\Love_in_nwafu`。
2. 标题界面选择「开始游戏」进入第一天，或选择「预告 Demo」查看序章预告。
3. 开始游戏后可修改主角姓名，默认「白行简」。

剧情与对白在 `game/content/` 下的 `.rpy` 文件里，改完保存即可重新运行；`game/saves/`、`game/cache/` 是运行产生的存档与缓存，不随仓库提交。

## 本地资料

个人原始照片、未确认许可的参考图和填写中的私人故事，请放到项目目录内的 `private/`。此目录已被 Git 忽略，不随正常提交上传。已填写的原始资料完整保存在本地 `private/notes/`；公开填写模板保持空白，已确认的虚构角色设定分别整理到人物卡。

以后可以直接在对话里提供角色、故事、照片和修改意见，由制作方整理进对应目录，不必手动填写全部文档。

仓库中的 `assets/` 只收录确认可随项目分发的素材。引擎安装文件、存档和构建产物不入库。

本项目尚未选择代码开源许可证和原创内容二创许可；公开仓库不代表第三方素材自动获得再分发授权。正式发布前会分别明确。
