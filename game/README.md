# 游戏运行目录（预留）

这里将成为 Ren’Py 项目的 `game/` 目录。目前只建立分类文件夹，没有入口脚本或可运行游戏。

- `scripts/`：地图、时间、关系、小游戏和未来 MOD 加载等系统逻辑。
- `content/main/`：主线脚本。
- `content/colleges/veterinary/`：动医专属脚本。
- `content/colleges/mechanical/`：机电后续内容。
- `content/characters/`：各人物正式剧情脚本，按角色编号分目录。
- `images/characters/`、`backgrounds/`、`maps/`、`ui/`、`cg/`、`minigames/`：经过选择、确认可发布的最终图片。
- `audio/bgm/`、`sfx/`、`ambience/`、`voice/`：游戏音频。
- `fonts/`：游戏所需字体及许可。
- `mods/`：未来玩家 MOD 安装位置预留；加载格式、启停与存档兼容尚未实现。

不将生活照、参考作品、PSD／KRA／Blender 原稿复制进这里。源文件留在 `assets/` 或 `private/`。创建真正的 Ren’Py 工程时再生成 options、screens、gui 和入口脚本。
