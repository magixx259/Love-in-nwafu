# 农农 · 外观设定

编号：CH03。此文件描述设计要求；图片和模型放在[美术目录](../../assets/characters/ch03_nongnong/README.md)。

## 已确认方向

以官方农农形象为参考，把官方校园形象转化为"下地也能穿"的大学生日常。需补官方出处与必须保留的辨识特征。不得把创作补充声称为官方设定；官方形象的改编与发行范围待确认。

## 设计方向（提案，待用户确认）

| 项目 | 方向 |
|---|---|
| 整体气质 | 安静、耐看、不抢眼但有细节 |
| 发型 | 低马尾或松麻花辫，碎发多，方便下地 |
| 发色 | 偏深，与官方农农配色一致 |
| 眼神 | 平时不看人，说话时才抬眼看一下 |
| 身高与体态 | 中等，站姿稳，手上有薄茧 |
| 日常服装 | 大地色（绿／棕／米）＋耐磨长裤＋帆布鞋 |
| 场景服装 | 草帽／围裙／袖套，下田时换 |
| 配饰 | 手腕上一条旧绳、包里露出种子袋或标本夹 |
| 必留／避免 | 保留官方辨识色与标志物；避免土气化、苦情化或过度装饰 |

以上为设计提案，待用户确认后定稿。
