## 设计方向（提案，待用户确认）

| 项目 | 方向 |
|---|---|
| 整体气质 | 热闹、易接近，像随时准备出门 |
| 发型 | 高马尾，发尾微外翘；跑动时马尾是她的动态识别点 |
| 发色 | 偏暖的亮色，与官方西西配色一致 |
| 眼神 | 直视对方，笑起来眼睛先笑 |
| 身高与体态 | 中等偏高，动作幅度大 |
| 日常服装 | 运动外套＋短裙或工装裤，方便跑动 |
| 配色 | 暖亮色系（橙／黄／白），与俞菲的冷色系形成对照 |
| 配饰 | 挂满徽章的帆布包、手机不离手、钥匙扣 |
| 实验服 | 白大褂永远少扣一颗扣子，口袋塞着记事本 |
| 必留／避免 | 保留官方辨识色与标志物；避免画成纯搞笑吉祥物或过度成熟 |

以上为设计提案，待用户确认后定稿。
