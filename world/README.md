# 校园与课程资料

- `locations/`：地点卡。名称、校区、年代、位置来源、照片出处、游戏改编说明。
- `maps/`：地图节点、相邻关系和路线说明；图片原稿放 `assets/maps/`，未经许可的原图放 `private/references/`。
- `colleges/veterinary/`：动物医学院资料。
- `colleges/mechanical/`：机械与电子工程学院资料，后续开放。
- `courses/`：知识点、题目、答案解释和可核对的参考来源。

已有的[官方校园参考](../docs/day01/05-campus-references.md)继续保留原路径，不重复下载和复制。地点卡引用该记录即可。用户的私人住址或房间信息不写入公开地点卡。
