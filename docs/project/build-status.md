## 现在能玩到什么

1. 标题菜单（开始游戏 / 预告 Demo / 读取存档 / 设置 / 关于 / 帮助 / 退出），全中文。
2. 「预告 Demo」：约 1 分钟的角色亮相预告，放完回标题。
3. 「开始游戏」→ 序章：交卷 → 考后空落 → 出分 → **志愿填报表单** → 录取通知书 → 车站 → 班助俞菲来电 → 报到日。
4. 第一天前半：北校区南门 → 改名 → 报到 → 西西登场 → 地图二选一 → 动医楼参观 → 四选一知识题（含提示、跳过）→ 回宿舍收尾。

背景与立绘全部是**占位图**（纯色渐变色块 + 地名/人名标签），没有音乐和音效。
