# 当前设定与制作范围

更新：2026-11-03。依据用户在对话和本地填写资料中确认的内容。与早期构想冲突时，以本文件为当前范围；尚未决定的内容不自动补成定案。

## 已确认

- 单机 Ren’Py 视觉小说，计划支持 MOD 和二创；具体接口与许可尚未完成。
- 第一阶段仅制作动物医学院路线。机电及其他学院保留未开放入口。
- 主角默认名字白行简，玩家可以改名；内向、腼腆，对新同学、课程、动物实验和恋爱既期待又紧张。
- 女主制作编号：CH01 俞菲姐、CH02 西西、CH03 农农。独立人物感情线是长期目标，不强制三人首日都登场。
- 从北校区南门入校，报名后与西西参观动物，之后回宿舍休息。
- 用户提到猪、牛、羊、兔子、小鼠、鸡和比格犬；实际参观区域、活体或标本形式待核实。
- 食堂采用第五餐厅；第一天用餐具体放在参观前、后或休息后尚未固定。
- 风格轻松、搞笑，表现初入大学时开心、好奇和迷茫。
- 专业互动优先考虑动物解剖学和形态特征，题目可以由制作方拟定并查证。
- 地图按实际布局略作游戏化处理，不展示真实私人信息。宿舍细节只保留在本地原始记录，公开版本暂称「宿舍」。

## 设计处理

- 只有动医一条可玩路线时，先展示录取／身份揭晓，不做「看似随机但必定抽中动医」的假选择。多学院随机抽取留到至少两条路线开放后实现。
- 未来学院随机分配属于虚构玩法，不宣称现实招生如此。
- 第一天的动物参观和知识互动可以先用占位图与临时对白实现，未确认细节注明草稿。
- 解剖学互动先用易读示意图做辨认题，具体知识来源记入课程资料。
- 三位女主和男主的设定分别在 `characters/` 维护；这里只记录项目范围，避免多处复制完整人物卡。
