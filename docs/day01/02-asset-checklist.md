# 第一天素材清单

目前所有条目均为「待制作／待提供」，仓库里没有正式图片、音频或已核实的校园地图。下表区分可马上做的占位内容与需要真实参考的正式素材。

优先级：P0 = 骨架必须具备但可以占位；P1 = 公开试玩前补齐；P2 = 后续润色。

## 背景与地图

|---|---|---|---|---|
| BG01 | bg_campus_arrival_day.webp | 实际入校入口或迎新区域，横向照片 1～2 张，注明拍摄地点与朝向；入口由用户确认 | 纯色背景＋「校门／迎新区」文字 | P0/P1 |

| BG03 | bg_mech_building_day.webp | 机电方向报到／参观地点，建筑外观或大厅参考，核实位置 | 几何占位背景＋暂定地点名 | P0/P1 |

正式背景推荐 1920×1080，保留无损原稿；游戏用图可用 WebP 或 PNG。画面底部约四分之一会叠加对话框，关键路标与人物不要只出现在底部。照片不足时可先用 1280×720 草图，不为占位稿追求精细度。

地图按真实位置关系重绘为易点击的简化图，不直接把所有现实细节塞入屏幕。正式公开版本所用原图与改编权需记录；示意图不作为现实导航。

正式角色推荐透明 PNG，统一画布和脚底／腰部基线，同一角色各表情不能跳动。可采用 1000×1600 工作画布，最终尺寸随画面布局调整。第一批为三位女主各一套基础形象、三种表情，共九个展示状态；不要求九张完全重画的立绘。

角色编号只是制作标识，不代表最终姓名或人物设定。官方形象的改编与发布条件未确认前，不将下载的原图或改编立绘直接提交到公开仓库。

## 第一批最小交付包

你优先提供：一份北校区地图参考、校门／两学院地点／食堂的各一张照片（有多少先给多少）、西西农农的官方参考链接，以及一件真实小事。照片没有也能先开发，不必为了凑齐清单暂停项目。

制作方可先完成：示意地图、基础界面、学院卡片、姓名框、临时对白、两道体验题草稿、示例 MOD。正式立绘、转绘背景、音乐遴选在方向确认后进行。
