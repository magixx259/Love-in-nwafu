# 资料填写模板

可以只填知道的部分；不需要一次全部完成。含个人信息的填写版本请复制到本地 `private/notes/` 后再写，不要直接填进这个公开模板。

## 1. 校园地点

- 北校区地图参考链接或本地文件：
- 地图年份／是否与当前校园一致：
- 从哪里入校：
- 动物医学方向第一天去哪里：
- 机电方向第一天去哪里：
- 食堂选择及位置：
- 宿舍是否使用真实名称：
- 地图上希望标注的其他地点：

照片建议命名：`地点_朝向_白天或夜晚_序号.jpg`。不确定方位可以不写。旁边附一句说明，比只发一批没有地点信息的图片更有用。

## 2. 一件真实校园小事

- 发生在什么时候、哪里：
- 谁在场（可用化名）：
- 事情经过：
- 最记得的一句对话或一个细节：
- 当时感受：
- 希望改编成轻松／搞笑／温馨／紧张的哪一种：
- 哪些细节不希望进入游戏：

## 3. 女主设定（每位复制一份）

- 制作编号：CH01／CH02／CH03
- 姓名或昵称（未定可空）：
- 外观参考链接或本地图片：
- 希望保留的外观特征：
- 三个性格关键词：
- 她想达成的一件事：
- 她的弱点或小烦恼：
- 与男主最初的关系：
- 你想看到的一次相遇：
- 不希望出现的设定：

西西、农农另附官方发布出处；官方资料没有说明的内容不要当作官方设定填写。

## 4. 男主

- 玩家自由输入姓名，还是固定名：
- 性格和说话方式：
- 入学时最期待／最担心什么：
- 哪些本人经历可以改编：

第一天不需要上传本人照片。之后若做肖像转绘，再单独挑选参考。

## 5. 学院与专业体验

- 学院正式名称和可靠出处：
- 新生第一天真实会接触的活动：
- 适合改编的小知识点：
- 对应教材／课程资料／网页出处：
- 哪些专业细节希望重点体现：

## 6. 喜欢的作品参考（可选）

- 作品名：
- 截图或短片文件／链接与时间点：
- 喜欢的是界面、对白、演出、音乐氛围中的哪一项：
- 最希望借鉴的一点：

参考用于讨论设计，不直接作为可分发的游戏素材。无需提供完整商业游戏安装包。
