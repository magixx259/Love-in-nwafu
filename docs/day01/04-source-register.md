# 素材来源与许可登记

当前没有已入库的正式游戏素材。已获取的官方图片仅存本地参考目录；出处、文件名、核实结果与使用说明见[校园参考收集记录](05-campus-references.md)。找到参考不等于已获得游戏改编和再分发许可。

## 状态定义

- 待核实：只有参考来源，或使用条件不明确；文件放本地 `private/references/`。
- 仅供参考：用于地点、构图、色彩和演出讨论，不作为游戏发布素材。
- 可入库：核实可改编（若做修改）和可再分发，并满足署名等条件。
- 已替换／停用：保留历史来源记录，但不再作为当前游戏资产。

## 不同类型的记录要求

- 自己拍摄的照片：记录拍摄者、地点、日期及公开范围；可识别人物、车牌或宿舍私人信息在发布素材中按需要去除。
- AI 转绘或生成图：记录工具／模型版本、生成日期、输入参考来源、所用服务的相关条款及人工修改；生成流程不会自动消除输入素材的使用限制。
- 官方形象和校园地图：记录官方出处及明确的使用条件；“官网能下载”不等于可以改编后开放给 MOD 作者再分发。
- 音乐、音效与字体：按具体作品及具体版本核实，保留许可文件；将必要署名汇总到游戏鸣谢。
- 游戏截图／片段：登记为设计参考，不混入可发布的素材目录。

任何未明确的字段写「待核实」，不自行推定授权。代码开源许可、原创故事二创许可和第三方素材许可分别管理。
