# 剧情工作目录

- `main/day01/`：第一天公共流程与场景稿。
- `colleges/veterinary/`：动医参观、专业知识互动等学院专属事件。
- `colleges/mechanical/`：机电后续内容预留，当前不制作。
- `side_stories/`：食堂、乐跑、公共课等可复用校园支线。
- `drafts/`：未采用的创作提案，不放未经处理的真实私人经历。

人物关系发展的大纲统一在 `characters/<角色>/route.md`；此处存具体场景，不重复维护完整人物卡。Markdown 为编剧稿，确认后再转成 `game/content/` 内的 Ren’Py 脚本。

每段场景建议注明：事件编号、适用学院、地点和时段、出场角色、触发条件、对白与选项、退出条件。第一版不为预留功能虚构已经实现的接口。
